# SaveMe

> 코드 기록용으로 업로드한 리포지토리입니다.  
> 리소스 및 외부 라이브러리는 포함하지 않습니다.  
> 프로젝트를 실행할 수 없습니다.  

## 📌 프로젝트 개요
퍼즐을 풀어 아이템을 모아 클리어하는 쯔꾸르 게임


### 🛠 개발 환경
- Language: C++14
- Libraries: Win32 API, FMOD, Msimg32, WinMM
- Platform: Window 11, visual studio 2022

### 🔗 리소스 출처
- 아트 리소스: 게임인재원 5기 아트반 (2명)
- 배경음악: 아트 팀장의 대학 동기
- 그 외(효과음, 폰트 등): 기획자 서치

## 🔧 개선사항
- 각 씬의 게임 오브젝트들을 모두 하드코딩 하였다. (불러오기x)
- FMOD 를 이상한 방식으로 프로젝트에 추가하였다.
- 함수, 클래스 등의 재사용성이 좋지 않고, 너저분한 코드가 많다.
- 코딩 컨벤션을 잘 지키지 못했다.
- 날짜를 맞추기 위해 FMOD 의 오류를 잡지 못한채로 오디오 관련 라이브러리를 하나 더 사용했다..
- 실력 부족과 일정 관리 실패로 기획자의 요구를 잘 들어주지 못했다.
